State 2

This is the first state where we test change in security posture of the domain due to a change in ACL permissions.

mdsiraj was given ResetPassword on vkohli to see how AD-AuthGraph tracks the change in state of the domain from State 1.

The script refiner.py is also included in the pipeline, from this state onwards.

Although analyzer.py finds all possible relationships, permissions and paths; the script was not able to organize the data for actionable insight.

refiner.py is able to highlight actual privilege escalation flows.


Contents of the folder:
               
                1. ad_authorization_state: JSON file generated from the collected raw Active Directory data at this current state, by Collect-ADAuthorizationState.ps1
                2. ad_authorization_state_graph: JSON file generated by graph_builder.py, contains a directed graph created from the raw data.
                3. ad_authorization_state_analysis: JSON file generated by analyzer.py, contains relevant data from the graph which determines the authorization flow and security state of the domain.
                4. ad_authorization_state_refined: JSON file generated by refiner.py, declutters the data generated by analyzer.py to show the important authorization flows.
                5. ad_authorization_state_report_refined: HTML report generated by visualizer.py by using the refined data.
                6. Screenshots of Blues-DC PowerShell terminal commands and responses as evidence of applied ACLs.
