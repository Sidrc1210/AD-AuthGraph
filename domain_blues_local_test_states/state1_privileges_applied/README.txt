Contents of the folder:
                1. apply_acl.ps1: PowerShell script to apply the above ACL permissions
                2. ad_authorization_state: JSON file generated from the collected raw Active Directory data at this current state, by Collect-ADAuthorizationState.ps1
                3. ad_authorization_state_graph: JSON file generated by graph_builder.py, contains a directed graph created from the raw data.
                4. ad_authorization_state_analysis: JSON file generated by analyzer.py, contains relevant data from the graph which determines the authorization flow and security state of the domain.
                5. ad_authorization_state_report: HTML report generated by visualizer.py by using the analysis data.
                     https://sidrc1210.github.io/AD-AuthGraph/domain_blues_local_test_states/state1_privileges_applied/ad_authorization_state_report.html

                     Note: Folder names are case-sensitive; use links as provided.

                6. Screenshots of Blues-DC PowerShell terminal commands and responses as evidence of applied ACLs.
  
Note: No ad_authorization_state_refined.json here because refiner.py was not included in the pipeline yet. It was applied in the later states as better mapping of acl edges became a requirement.
